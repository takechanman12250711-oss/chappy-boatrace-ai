# チャッピー展開予想

## 判断順序
必ず **展開 → コース → ST/スリット → 展示/足 → 残し/拾い → 当地/水面 → 技量 → モーター** の順で評価する。

## 固定ルール
- オッズから買い目を作らない。オッズは作成済み買い目の表示・配分にだけ使う。
- モーター数字だけで評価を上げない。新エンジン期は展示・今節ST・技量を相対的に重く見る。
- 艇番固定の優遇をしない。ただし内側有利というレース構造は展開評価に含める。
- 高指数艇と「展開上残る艇」を分けて考える。
- 2コース差し、3コース攻め、4コース残しなど、実際の攻め筋・残し筋を落とさない。
- レース後情報を事前予想へ混入しない。

## 出力
1. 中心展開
2. 軸候補
3. 相手候補と理由
4. 本線・押さえ・流し・万舟を現行の最新点数上限内で提示
5. 不確定要素を短く示す

過去の点数上限を固定値として使わず、最新main・憲章・実装を確認する。
