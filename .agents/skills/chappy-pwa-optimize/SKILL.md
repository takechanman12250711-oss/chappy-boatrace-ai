# PWA軽量化

## 優先順位
1. 不要JS・未使用処理の削除
2. 初期表示に不要な処理の遅延
3. オッズ・結果分析など選択後でよいAPIの遅延
4. 重複イベントリスナー・再描画の削減
5. API呼び出し回数と同一データ再取得の削減
6. 画像・CSS・DOMのスマホ表示最適化

## 制約
- GitHub Pagesフロント + Vercel API の現行構成を大きく変えない。
- 無料運用を優先し、有料サービス前提にしない。
- 新機能追加ではなく、既存挙動を維持したまま速くする。
- prediction.jsの計算責務とrender.jsの表示責務を混ぜない。

## 完了条件
変更前後で表示、主要操作、API取得、エラー、体感に関係する指標を確認し、速度改善のために予想ロジックや表示内容を削らない。
