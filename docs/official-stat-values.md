# 当地勝率・モーター率は公式の数字を使う（2026-10-27 本人決定）

## 決定

予想エンジン（ai-core）へ渡す各艇の「当地勝率・当地2連率・当地3連率」と「モーター・ボートの率」は、公式出走表の数字のまま使う。

## 以前の動き

- `js/history-insights-base.js`（水面相性 v2）が、正式評価のときに当地の3つの率を採点から作った数字（`syntheticLocalStats`）で上書きしていた
- `js/motor-maintenance-insights.js`（モーター整備 v2）が、正式評価のときにモーター・ボートの率を採点から作った数字（`encodeMotorScore`）で上書きしていた
- 上書きした数字が同じ名前のまま保存・表示され、予想の理由に「当地勝率3位 5.82」（公式は 4.88）のように出ていた

## 変更後

- 2つの上書きをやめた。採点（`localWaterTheoryV2`・`motorMaintenanceTheoryV2`、`encodedMotor` を含む）は根拠として艇ごとに残す
- 予想・保存・表示の「当地勝率」「モーター2連率」は公式の数字になる
- 過去に保存した予想は書き換えない

## 根拠

`data/stats/official-stat-slots-comparison-v1.json`（PR #1384）。2026-10-01〜10-27、確定896レース：

| | 上書きあり（以前） | 公式の数字 |
| --- | --- | --- |
| 的中 | 217 | 217 |
| 回収率 | 69.96% | 70.61% |

当たり外れが入れ替わったのは14レース（7対7）。成績に差はなく、表示と保存データの正しさで公式の数字を選んだ。

## 影響を受けた研究の扱い（2026-10-29）

予想ファイルを固定して測っていた「本命入れ替えの前向き検証 v2」（`config/independent-head-forward-v2.json`、PR #1350）は、この変更で固定ファイルが一致しなくなり、新しいレースを集めなくなった（本人は承認時に了承）。live-note はその後も研究の停止を毎回「失敗」として表示していたため、`config/independent-head-forward-v2-closed.json` に終了の記録を置き、live-note はこの研究の取得工程を実行しない。保存済みの記録と安全装置（固定ファイルの照合）はそのまま。再開する場合は新しい protocol を登録する。
