# 1-4 third-place rescue fixed5

- 対象: 現行固定5点に `1-4-3` が存在
- 代替候補: 2/5/6のうちpickup最大艇
- 判定: 代替候補−3号艇の差
  - 展示 <= -0.13
  - raceFlow <= 5.2
  - hold <= 5.7
- 3条件中2つ以上で `1-4-3` を `1-4-X` に1点交換
- 固定5点数は不変
- オッズは判定に使用しない

- holdout: +1的中 / +6,280円
