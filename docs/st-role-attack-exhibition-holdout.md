# ST優位＋攻め役割優位＋展示優位 未使用holdout検証

## 目的

`flow-suppression-v2`で、3・4号艇勝ち群と1号艇勝ち群を分ける材料として`raceFlow`単独差は不足し、展示差が独立信号候補として残った。

同じDiscoveryで閾値を探さず、未使用holdoutを一度だけ開封し、次の固定複合条件を検証する。

## 固定仮説

現行baselineの1着評価が1号艇であるレースに限り、3・4号艇のうち次を全て満たす艇をshadow頭候補とする。

- ST加重点が1号艇より高い
- 攻め役割加重点が1号艇より高い
- 展示加重点が1号艇より高い

複数艇が該当する場合は、現行baseline順位が上の艇を使う。実結果、オッズ、払戻は適格判定・候補選択に使わない。

## holdout分離

- 既存のholdoutローダーを最優先する
- DiscoveryとraceKeyが1Rでも重なれば停止する
- holdoutのraceKey一覧をSHA-256化して保存する
- この検証でholdoutは消費済みとする
- 結果を見た後の閾値変更・同じholdoutでの再試験は禁止する

## 事前固定した判定条件

| 条件 | 固定値 |
|---|---:|
| holdout全体 | 100R以上 |
| 複合条件該当 | 15R以上 |
| 各半期の該当 | 5R以上 |
| shadow候補が実際に勝った例 | 3R以上 |
| 正解純増 | 2R以上 |
| 該当群の精度改善 | 5pt以上 |
| 対応あり片側検定 | p ≤ 0.20 |
| 切替率 | 20%以下 |
| 前半・後半 | 両方とも正解純増0以上 |
| Discovery重複 | 0R |

全条件を満たした場合だけprospective shadowへ進む。本番採用にはしない。

最低件数を満たした後に安全条件を外した場合は、閾値を調整せず固定複合条件を棄却する。

## 測定項目

- 現行頭とshadow頭の正解数・正解率
- 不正解→正解
- 正解→不正解
- 不正解→別の不正解
- 1号艇勝ちの喪失数
- 3・4号艇勝ちの救済数
- 切替率
- 前半・後半の再現性
- Discoveryとの重複数

## 安全性

- 予想ロジック変更なし
- 買い目・点数・UI変更なし
- 2コース差し・4号艇残しを削除しない
- 3・4号艇を一律に昇格しない
- オッズ・払戻不使用
- 自動本番反映なし
- 本番反映にはユーザーの明示承認が必要
