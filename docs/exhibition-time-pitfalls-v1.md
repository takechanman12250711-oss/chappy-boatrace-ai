# 展示タイムの落とし穴 検証 v1

更新日: 2026-10-22

## 位置づけ

YouTube「【極秘】"展示タイム"を見るだけでは勝てません｜本当の使い方を完全公開」（https://youtube.com/watch?v=UH2qqLJoKOo ）の「展示タイム1位＝買いではない」理由3点を、締切前保存予想と公式結果だけで確かめた**研究集計**。`chappy-source-research` の「外部理論をshadowで検証する手順」に従う。

- `productionChanged=false` / `automaticApplication=false` / `usableForPrediction=false`。本番予想・買い目・UI・noteは変えない
- 主張の出典はユーザーが作成した動画要約（動画本体は未視聴）
- 入力は `data/predictions`（`analysis-input-contract` の締切前判定を通したもの）と `data/results`。新しい収集・cron・有料APIは追加しない

再生成: `node scripts/build-exhibition-time-pitfalls.cjs` → `data/stats/exhibition-time-pitfalls-v1.json`

## 結果を見る前に固定した条件

| 項目 | 値 |
| --- | --- |
| 対象 | 6艇の展示タイム（6.0〜7.5秒）・公式進入・風速・波高がそろい、公式結果があるレース。欠場艇のいるレースは除外、完走しなかった艇は最下位タイ |
| 期間 | explored 2026-07-22〜09-15 / holdout 2026-09-16〜 |
| ① 引き波 | 艇番ごとに「展示タイム − レース内平均」を集計。exploredの値で補正した展示順位と、補正なしの順位を比べる |
| ② 荒れ水面 | 風速5m以上または波高5cm以上を「荒れ」とし、穏やかな水面と比べる |
| ③ 計測位置 | 尼崎（13）・徳山（18）・福岡（22）・大村（24）とその他の場を比べる |
| 指標 | 展示タイム最速艇の1着率（同タイムは等分）、展示順位と着順の順位相関（1レースごとのスピアマン相関の平均） |
| 結論に使う件数 | 100R以上 |

対象外: 目展示（行き足・ターン）と、周回展示バックストレッチの走行位置。記録がないため。

## 読み取り

1. **① 1号艇の展示タイムは速く出る。ただし差し引くと予想が悪くなる。** 1号艇は両期間とも平均より約0.02秒速く、外枠ほど遅い（動画の主張と同じ向き）。しかし、その差を差し引いた展示順位は、最速艇の1着率が28.7%→21.4%、順位相関が0.173→0.097（holdout）と下がった。艇番の差には引き波だけでなく、内枠の艇が実際に強い分も含まれていて、データからは分けられない。単純な艇番補正は採用候補にしない。
2. **② 荒れた水面では展示タイムの当てになり方が下がる。** 両期間とも、荒れた水面のほうが最速艇の1着率（30.5%→26.4%、29.3%→24.6%）と順位相関（0.197→0.161、0.179→0.129）が低い。向きは動画と同じだが、holdoutの荒れ水面は94Rで、結論に使う100Rに届かない。前向きに件数を増やして確かめる。
3. **③ 計測位置が異なる4場で、決まった違いは見えない。** exploredでは4場のほうが高く、holdoutではほぼ同じで、向きがそろわない。件数も少なく、場の水面特性とも区別できない。

## 未検証・既知の限界

- 目展示（行き足・ターン）と周回展示の走行位置は検証していない。
- 1着率・順位相関には進入コースの有利不利が含まれる。展示タイムが「コースを考えたうえで」どれだけ上乗せになるかは、この集計では分けていない。
- 期間は約3か月で、季節や開催の偏りが残る。
- 本番の予想にはすでに内隣との展示タイム比較（`docs/adjacent-exhibition-v1.md`）が入っている。この集計はそれとは別の参考値で、比較や置き換えはしていない。

## 次に検証できること

- ②の荒れ水面は、前向きに件数を増やして同じ条件で確かめる。採用を考えるのは、holdoutでも100R以上で同じ向きが出てから。
- 採用する場合は、予想ロジックの変更として本人の承認を別に得る。
