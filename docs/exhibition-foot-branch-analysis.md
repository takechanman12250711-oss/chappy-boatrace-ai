## 独自計測の取得状況と参考順位

既存の枝別成績・母数・会計を維持し、同じレポートの `originalMetrics` に、一周・まわり足・直線を独立した項目として追加する。入力は予想時点に保存された `preRaceConditions.originalFootEvidence` であり、現在の公式ページで過去の欠測を補完しない。集計用の縮約でも、この参考情報と時刻判定に必要な項目を保持する。

- 対応場は浜名湖（06）。他場の未対応、旧原本の項目なし、取得失敗・不一致、計測不足、比較可能を区別する。
- 保存された値・出典・計測定義・6艇の対応が揃う項目だけ比較する。一項目の欠測で他の項目を除外しない。
- 結果との対応は、共通の締切前入力条件を満たし、公式の有効な確定結果を結合できる場合に限る。結果待ち・返還等・入力不適格は原因別に残し、0%的中へ置き換えない。
- 参考順位の同順位は保持する。最上位の同タイム艇を艇番で一艇へ絞らず、順位一致は同順位を含む計測群の記述的集計として読む。

この節は計測の取得状況と着順との参考対応であり、買い目の的中率、採点効果、因果関係、性能改善の証明ではない。source取得時刻と締切前のremote sealは別の証拠として扱い、レポートだけからremote保存済みと判定しない。予想・買い目・重みは変更せず、新しいcron・writer・レポートファイルも追加しない。既存の結果収集と診断保存経路で更新する。
