# 当地・水面 5・6号艇・priorityScore選択整合性監査 v1

## 目的

当地・水面の正式証拠と公式結果が揃った同一コホートで、実際に勝った5・6号艇が、同じ締切前保存済み候補配列内で最終頭以上の`priorityScore`を持ちながら選択されなかった例を監査する。

対象は上流監査が固定した9Rだけで、結果後に新しい特徴量や条件を追加しない。

## 確認項目

- 勝ち艇候補と最終頭候補の`priorityScore`
- 同点時の候補配列順
- `selected`・`adopted`・`qualified`等の保存済み状態
- 明示された除外・見送り理由
- 重複・同一買い目の抑制信号
- 頭・攻め・相手・拾い等の保存済み役割

## 一次分類

- 勝ち艇スコア上位なのに選択逆転
- 勝ち艇スコア上位だが明示的に除外
- 同点で最終頭が配列前方
- 同点で勝ち艇が配列前方なのに落下
- 同点かつ重複理由で除外
- 同点かつその他の明示的除外
- 同点だが保存済みtie-break根拠なし
- 比較配列・比較行・予想記録の欠落

## 結果を見る前に固定した次工程

1. 対象5R未満：証拠収集を継続
2. 比較行解決率80%未満：選択過程の観測性を改善
3. スコア上位逆転が2R以上：priority selectorのshadow replayを作成
4. 重複信号が50%以上：重複処理と選択順を監査
5. 同点5R以上かつ最終頭前方が60%以上：tie-break順を監査
6. 勝ち艇の明示的除外が5R以上：除外契約を監査
7. その他：選択器構造を監査

## 安全性

- 予想ロジック変更なし
- 買い目・点数・UI変更なし
- オッズ・払戻不使用
- 本番自動適用なし
- 診断専用
