# 当地・水面 priority selector shadow replay v1

## 目的

当地・水面の正式証拠と公式結果が揃った確定群全体で、保存済み候補配列の`priorityScore`を使った最小変更ルールを反実仮想検証する。

上流監査では、実際に5・6号艇が勝った例のうち、同じ候補配列で勝ち艇の`priorityScore`が現行最終頭より高いのに落ちた例が2R、同点で配列後方に置かれた例が7R確認された。

## shadowルール

- 対象候補配列：`practicalSelection.frameRiseFallReplayBasis.raceScenarios.mainScenario.branches`
- 艇ごとに保存済み`priorityScore`の最高値を採用
- 候補の最高点が現行最終頭より**厳密に高い場合だけ**shadow頭へ切り替える
- 同点は現行最終頭を維持する
- 候補配列または現行頭スコアを取得できない場合も現行頭を維持する
- 実結果はshadow頭を選ぶ条件には使用しない

## 測定項目

- 現行頭とshadow頭の1着正解数・正解率
- 不正解→正解、正解→不正解、不正解→別の不正解
- 5・6号艇勝ちの救済数と喪失数
- 5・6号艇への誤昇格数
- 救済1R当たりの誤外枠昇格
- 外枠昇格レース率
- calm・medium・strong別の精度変化
- 頭艇分布と切替遷移

## 結果を見る前に固定した判定

1. 当地・水面確定群300R未満：証拠収集を継続
2. 現行頭取得率90%未満：現行頭の観測性を改善
3. 比較可能100R未満、または比較被覆50%未満：shadow replayの観測性を改善
4. 厳密なスコア上位への切替2R未満：切替証拠を継続収集
5. 次を全て満たす：前向きshadow A/Bの準備へ進む
   - 全体正解純増2R以上
   - 5・6号艇勝ち救済2R以上
   - 正解→不正解0R
   - 誤外枠昇格／救済1Rが3件以下
   - 外枠昇格レース率10%以下
   - 30R以上ある水面条件で2pt超の精度悪化なし
6. 全体精度悪化または正解喪失が救済を上回る：ルール棄却
7. 水面条件別の安全条件だけ未達：条件別悪化を監査
8. 純増・外枠救済が最低値未満：証拠収集を継続
9. 外枠誤昇格上限超過：外枠昇格リスクとして棄却

## 安全性

- 診断専用
- 予想ロジック変更なし
- 買い目・点数・UI変更なし
- オッズ・払戻不使用
- 同点時の外枠優遇なし
- 本番自動適用なし
