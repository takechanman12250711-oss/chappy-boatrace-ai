# 当地・水面 5・6号艇・頭役割資格監査 v1

## 目的

前工程のボトルネック監査で保存された実5・6号艇勝利例だけを使い、勝ち艇が頭候補になれなかった主要因を固定分類する。

## 一次分類

- 相手・拾い役として見えているがhead役割がない
- 1着適格位置がない
- role intentにheadがない
- 明示的な頭役割契約がない
- 保存済みの外枠頭根拠がない
- 候補が除外・未選択
- 頭候補から頭シナリオへ上がらない
- 頭シナリオから選択順位で落ちる
- 選択済み頭から最終main headへ渡らない

## 結果を見る前に固定した次工程

1. 対象20R未満：証拠収集を継続
2. 頭役割資格側の主要因が10R以上、かつ対象の40%以上：外枠頭適格性の反実仮想グリッドを作成
3. 資格側が条件未達で、シナリオ昇格・選択順位・最終引き渡しのいずれかが10R以上：該当する下流段階を監査
4. いずれも未達：証拠収集を継続

上流の診断焦点が頭役割資格でない場合、この監査は適用しない。

## 安全性

- 締切前保存済みデータだけを使用
- 結果後に新しい特徴量を作らない
- 予想ロジック変更なし
- 買い目・点数・UI変更なし
- 自動採用なし
