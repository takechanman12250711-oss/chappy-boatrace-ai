# 日和学習データ 採用候補・変更提案書

## 目的

採用候補に分類された学習項目について、予想へ反映する場合の対象範囲・補正上限・安全条件を提案書として表示する。

## 重要ルール

- 承認前は常に無効
- 予想ロジック、印、配点、買い目へ自動反映しない
- 展開 → コース → ST・スリット → 展示・足 → 残し・拾い → 当地・水面 → 技量 → モーターの優先順位を変更しない
- オッズは予想生成に使わず、表示・分類・資金配分だけに使う
- 数字だけで買い目を追加・削除しない
- 新エンジン期はモーター数字を過信しない

## 提案対象

- 展示・一周：展示・足の補正候補
- ST展示：ST・スリットの補正候補
- 気象・水面：当地・水面の補正候補
- 新エンジン・新燃料：モーター評価の補助候補
- 合成オッズ：表示・分類専用。予想値への加点なし

## 補正上限案

- 展示・一周・ST：最大 ±2〜4点
- 気象・水面：最大 ±2〜3点
- 新エンジン・新燃料：最大 ±1〜2点
- 合成オッズ：0点

上限は信頼度に応じて変わるが、提案書の段階では実際に適用しない。

## 自動保留条件

- サンプル120艇未満
- 信頼度72点未満
- 合成オッズなど予想生成に使わない項目

## 保存先

`localStorage` の `chappy_hiyori_adoption_proposals_v1`

## 読み込み

`js/hiyori-adoption-proposals-loader.js` を読み込むと、`js/hiyori-adoption-proposals.js` が起動する。
