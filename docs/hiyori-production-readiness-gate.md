# 日和学習データ 本番反映 最終判定ゲート

## 目的

相関信頼度、採用候補判定、変更提案の承認、シャドー検証成績を統合し、本番反映前の状態を自動判定する。

この機能は監査・判定専用であり、予想ロジック、印、配点、買い目には影響しない。

## 判定状態

- 反映不可
- 継続検証
- 最終承認待ち

## 最終承認待ちの主条件

- 採用候補判定を満たす
- 相関信頼度72点以上
- 相関サンプル120艇以上
- 変更提案が承認済み
- シャドー検証120件以上
- シャドー判定が採用検討
- 悪化率18％未満
- 総合準備度85点以上

## 安全ロック

保存される最終判定には常に以下を含む。

```js
productionApplied: false
applicationLock: true
requiresExplicitFinalApproval: true
globalProductionLock: true
appliedToPrediction: false
```

最終承認待ちになっても自動反映されない。

## 保存キー

```text
chappy_hiyori_production_readiness_v1
```

## 表示

- 判定件数
- 準備度スコア
- 反映対象
- 補正上限
- 不足条件
- 本番適用無効表示

## 更新タイミング

- 相関信頼度更新時
- 採用候補更新時
- 承認状態更新時
- シャドー成績更新時
- localStorage変更時
- 1分ごと
