# 外部3ソース前向き比較 契約 v1

更新日: 2026-09-30

## 目的

ボートレース日和・マクール・BR社の公開情報から、チャッピーボートレースAIの既存理論を改善できる要素を**前向き比較**する。
外部の宣伝値や買い目をそのまま本番予想へ採用しない。

## 共通ルール

1. 予想の優先順位（展開 → コース → ST/スリット → 展示/足 → 残し/拾い → 当地/水面 → 技量 → モーター）を変更しない。
2. 取得はログイン・課金・アクセス制限回避を伴わない公開範囲だけ。
3. レース開始前・結果未取得時点の情報だけを比較原本として保存する。
4. 外部ページの全文・有料文章・画像を複製しない。保存対象は比較に必要な数値、分類、公開URL、取得時刻、SHA256。
5. 公式結果は既存の BOAT RACE 公式結果原本と照合する。
6. 過去レースを結果を見てから選んで採用しない。
7. 外部データだけで買い目を追加・削除しない。
8. 自動本番反映は禁止。productionChanged=false / automaticApplication=false / usableForPrediction=false を固定する。
9. 採用判断は十分な前向きサンプルと、的中率・回収率・展開正答率・悪化条件を提示してユーザー承認後に別PRで行う。

## ソース別の研究対象

### ボートレース日和

公開範囲で確認できる項目を対象とする。

- 超展開データ: 1マークの攻め方、攻められ方、抵抗、絞り
- 逃がし時全艇複勝率: イン逃げ時の2・3着候補
- コース別の逃げ・差し・まくり・まくり差し系統
- 当日公開の出走・直前情報のうち既存公式入力と同じレースへ安全に対応付けできるもの

用途は「攻め艇」「残し艇」「拾い艇」「1逃げ時の相手」の比較。合成オッズは予想生成に使わない。

### マクール

公開されている若松のレース別予想ページを前向き比較に使用する。艇番号つきの事前短評から、逃げ・差し・まくり/握り・カド・スタート注目・足評価だけを構造化し、文章自体は保存しない。若松以外は同等の公開レース別ページを確認できるまで対象外とする。

スリット・展示・万舟/波乱の**表示・分類方法と、取得可能な事前情報**を研究する。
外部の有料予想・買い目を自動取得しない。
チャッピーのST/スリット、展示/足、波乱入口の判定と同一レースで比較できる公開項目だけ保存する。

### BR社

公開ページで確認できるマテマティクスの指数・公開時刻・対象場/レース・公開結果導線を研究する。
有料記事本文・有料買い目は取得しない。
公開サイトでは B/E/S/A/G/K/L/W の8指数の意味と利用方法を確認できるが、当日のレース別指数はnote/レジまぐで販売されている。公開範囲だけでレース別指数を取得できない間は、方法論を比較軸として保持するだけで、レース別データを捏造しない。将来、正規に利用可能なレース別原本が与えられた場合のみ、チャッピーの艇評価・展開候補との相関を比較する。
サイト記載の的中率などの宣伝値は検証済み成績として採用しない。

## 保存形式

`data/external-reference/YYYYMMDD/<raceKey>-<source>-<sha256>.json`

最低限:

```json
{
  "version": "external-reference-v1",
  "raceKey": "YYYYMMDD-JCD-R",
  "source": "hiyori | macour | br",
  "capturedAt": "ISO-8601",
  "beforeResult": true,
  "sourceUrl": "public URL",
  "sourceSha256": "...",
  "features": {},
  "productionChanged": false,
  "automaticApplication": false,
  "usableForPrediction": false
}
```

## 比較レポート

ソース別・項目別に以下を分離して出す。

- 前向き比較R数
- 展開一致率
- 1着候補一致率
- 2着残し/3着拾いの改善件数
- 現行買い目Aと参考情報を使った仮想Bの的中率
- A/B同額購入時の回収率
- 改善・悪化・同一の件数
- 場別、コース別、攻め艇別
- サンプル不足
- 取得失敗/未公開/対応不能

## 初期採用ゲート

これは**研究開始条件**であり自動採用条件ではない。

- 同一項目の前向き比較 120R以上
- 結果後取得 0件
- 原本整合性エラー 0件
- 的中率だけでなく回収率と展開正答率も悪化していない
- 特定場だけの改善を全24場へ一般化しない
- ユーザーの明示承認

条件を満たしても本番反映は別PRで行う。
