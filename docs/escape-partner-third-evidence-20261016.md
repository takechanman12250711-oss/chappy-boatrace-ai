# 1逃げ相手の3着役割・同点交換診断

## 結論

PR #1319で保持した「1号艇頭の2着多様化」は、2着組だけでは改善したが、3連単では改善しなかった。
保存済みの同じ99Rを再照合すると、追加できた4つの1・2着組はすべて同点交換で、選んだ3着は4Rとも実着と不一致だった。
正解3連単側に2着・3着両方の構造化役割が保存された例は0/4であり、現時点では根拠付きの3着可変版を固定できない。

同点を交換しない版は損失を止める一方、2着組の追加4件もすべて失う。したがって本番候補にはせず、
「同点交換を全面禁止」でも「結果に合う3着へ差し替え」でもない、締切前に保存できる2・3着役割の整備を次の課題とする。

## 同点交換の分離

公式進入・展示完備50Rで、優先点を下げない版の変更24Rは同点21R、上昇3R、低下0Rだった。

|---|---:|---:|---:|---:|---:|
|保存券|0|27|14|-|53.09%|
|優先点非低下|24|31|13|0/1|50.04%|
|優先点が厳密に上がる場合だけ|3|27|14|0/0|53.09%|

1・2着組の追加4Rと、平和島`20261013-04-4`の1的中喪失は、すべて同点交換で発生した。
厳密上昇だけに絞ると保存券と成績が同じで、的中率向上はない。これは既知期間の事後診断であり、新しい採用候補ではない。

## 今回の変更範囲と残作業

研究レポートに、保存済み`practicalSelection.targetDecisions`から候補ごとの構造化役割、同点/上昇の別、
厳密上昇だけの同一点数比較を追加した。選定器、予想券、採用gate、cron、過去原本は変更していない。

残る課題は、締切前の候補保存時に、compact preview外も含めた2・3着の構造化役割を小さい形で保持できるかを調べること。
旧99Rへ後付けせず、保存できた将来分を別期間で評価する。今回の既知期間は候補設計用で、本番採用や精度改善の証明に使わない。
