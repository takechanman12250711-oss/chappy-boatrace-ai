# 引き波越え実績ゲート v1（shadow検証）

## 目的

2コースより外の艇を1着（頭）にする根拠として、そのコースで内側艇の引き波を越えて勝った実績があるかを確認する。勝率・モーター2連率などの全コース平均の数字だけで外の艇を頭にしない、という考え方を締切前保存データで検証する。

## 結果を見る前に固定した判定

| 実進入コース | 条件 | 判定 |
| --- | --- | --- |
| 1コース | 引き波を受けない | `exempt-inside`（対象外） |
| 2〜6コース | 公式の実進入コース別履歴なし | `history-missing`（判定しない） |
| 2〜6コース | 3年間のそのコース出走が12走未満 | `insufficient-samples`（判定しない） |
| 2〜6コース | 「差し」「まくり差し」の1着が3年間で2回以上 | `qualified`（頭候補に残す） |
| 2〜6コース | 上記を満たさない | `demote`（頭から外し、2〜3着候補へ） |

- 「まくり」は外から全艇をかわし、引き波をほぼ通らずに勝つ形なので実績に数えない。
- 走数の下限12走は既存の選手コース適性（`buildRacerSkillTheory`）の正式判定と同じ。
- 実装は `js/wake-crossing-head-gate.js` の `FIXED`。

## 検証方法

- 入力は `data/predictions/YYYYMMDD.json` の締切前保存予想と `data/results/YYYYMMDD.json` の公式結果だけ（`analysis-input-contract` の締切前判定を使用）。
- 選手のコース別決まり手は、予想時に保存された `preRaceConditions.escapeEvaluationEvidence.racerSkillTheory.roles[].courseHistory` を使う。結果後のデータで後付けしない。
- A案：保存済みの実戦厳選券（`practicalTickets`）。
- B案：A案から、頭が `demote` の艇になっている券だけを除いたもの。新しい券は追加しない（点数合わせや数字だけでの追加をしない憲章に合わせる）。
- 1点100円で的中率・回収率を集計し、頭候補と全艇について判定別の1着率・2〜3着率を出す。
- 降格された頭が30件以上集まったら `readiness: evidence-ready`。

出力は `data/stats/wake-crossing-head-gate-v1.json`。

## 安全性

- 本番予想・買い目・UI・noteは変更しない（`productionChanged: false`、`usableForPrediction: false`、`automaticApplication: false`）。
- 保存済みの予想・結果を書き換えない。
- 本番採用には、検証結果を確認したうえで本人の承認が必要。

## v2：過去レースへの拡大とC案（2026-10-21）

出力は `data/stats/wake-crossing-head-gate-v2.json`（v1の出力は履歴として残す）。

### 当日以前の結果だけで再構築

予想時に選手のコース別決まり手が保存されていない過去レースは、`scripts/wake-crossing-point-in-time-history.cjs` が公式結果の原本から再構築する。

- 窓はレース前日を最新日とする1095日（`build-race-stats.js` と同じ幅）。当日以降の結果は使わない。
- コースは締切前保存の `preRaceConditions.boats` で、6艇すべて公式展示の進入がある場合だけその進入、なければ枠番（ai-coreと同じ扱い）。
- 保存済みの判定と再構築の判定は、重なる1,259R・7,554艇で99.5%一致した。

### 期間の分け方

- `explored`：保存済みの判定があるレース（v1の結果とC案の試算を見た期間）
- `holdout`：再構築で判定したレース。C案はこの期間を見る前に固定した

### C案（v2で固定）

降格艇が頭の券 `h-x-y` を `x-h-y` に置き換え、降格艇を2着へ回す。B案に残る券と重複する券、入れ替え後の頭も降格艇になる券（例：4・5が両方降格した `4-5-6` → `5-4-6`）は追加しない。後者はCodexレビューで見つかった定義の不整合の修正で、修正後の値を下表に示す（修正前との差は変更レース回収率で0.2〜0.4ポイント）。

### 初回実行の結果

| | explored（1,259R、9/22〜10/20） | holdout（2,468R、7/26〜9/22） |
| --- | --- | --- |
| 降格対象の頭 1着率 | 7.1%（170件） | 8.4%（357件） |
| 実績ありの外の頭 1着率 | 16.5% | 17.1% |
| 全体回収率 A / B / C | 85.0 / 88.7 / 88.0% | 71.8 / 74.0 / 72.1% |
| 全体的中R A / B / C | 308 / 306 / 318 | 586 / 580 / 592 |
| 変更レース回収率 A / B / C | 46.0 / 63.3 / 67.4% | 38.7 / 43.9 / 39.8% |

- 「実績なしの外の艇は頭として弱い」はholdoutでも再現した。
- B案（外すだけ）は両期間で回収率が上がった。
- C案（2着へ回す）はexploredの変更レースでは最良だったが、holdoutでは回収率がほぼ横ばいで再現しなかった。的中レースは増えるが、回収率の改善はB案に及ばない。
