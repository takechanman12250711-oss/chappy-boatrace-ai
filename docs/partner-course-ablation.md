# 逃げ展開の追加コース補正を外す研究

PR #1087 の凍結順位モデルを引き継ぐ原因切り分け。通常予想へは接続しない。

`partner-course-ablation-protocol.json` を結果確認前に固定。逃げの場合だけ、学習済み2着・3着コース係数12個を0にする。上流の展開・コース・ST・展示を含む2/3着点、2つの点数係数、他展開、同点規則、主頭、点数・頭別配分、別頭券の位置は維持する。外艇の強制追加・再学習・オッズ利用なし。

旧成果物のSHAを検査し、旧モデルの全券を再現してから、新候補を明示した入力項目だけで生成し、結果はその後に結合する。GitHubの専用PR検査で保存済み362行を比較する。新しい収集cronやWorkでの継続分析は作らない。元artifactが期限切れ・不一致なら停止し、同名の別データで補完しない。

全体と逃げ群、9/18〜23と9/24〜27を別表示する。元券比・旧順位モデル比の追加/喪失/純増と、同額100円の仮想回収率を併記する。これらは候補発案前に閲覧した期間であり、未使用holdoutや前向きの効果確認ではない。暫定進入も含む。

この変更は追加コース補正全体（2着・3着）の除去であり、STだけの因果効果や最適係数を証明しない。採用gate未登録・本番変更false。結果が良くても自動採用しない。候補固定後の新しい期間での評価と本番接続は別工程。

## 2着だけを切り分ける追加比較

同時除去で旧モデルから失った14的中のうち13件は、1・2着組が残ったまま3着券が消えた。追加仮説 `escape-second-course-ablation-v1` は2着コース係数6項だけを0にし、3着係数を保持する。同じ2着艇内で3着候補の相対順位・点差は保つが、ペア全体の採用枠で3着券が落ちない保証ではない。

新しい比較条件は `scripts/partner-second-course-protocol.json`。元の同時除去案は変更せず、共通比較器へ明示的に別選定器と別契約を渡し、別artifactに保存。前案の結果を見た後の仮説であり同期間は発見用。内訳が良くても自動採用しない。
