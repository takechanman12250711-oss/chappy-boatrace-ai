## 入力と出力

- 入力：`continuous-performance-ledger-v1` と同じコホート（締切前に保存した予想＋公式結果、`analysis-input-contract` の除外条件そのまま）。
- 出力：`data/stats/race-insight-report.json`。`seiseki.html`（全成績ページ）の下半分に表示。
- 更新：既存 `Build continuous performance ledger` の成功後に `Build race insight report` が実行（新しい cron なし、`chappy-main-data-writers` で直列化）。保存は ledger と同じ単一ファイル transport（`persist-continuous-performance-ledger.cjs` の `persist({output, builder, isValid})`）。

## 1. 荒れる／混戦／堅め（race-roughness-v1）

- 定義：3連単払戻 5,000円以上＝荒れた。
- 式：`config/race-roughness-v1.json` に固定したロジスティック回帰（14項目：1コースの級別・勝率・平均ST・他艇との勝率差・モーター差、他艇A1数、6艇の勝率のばらつき、外枠(4〜6)最強勝率−1コース勝率、風速、波高、場のイン1着率・荒れ率（2023/7/22〜2026/7/21の公式結果）、1R、12R）。
- 2026/9/28 より前の 2,682R で係数と境目（上位30%＝荒れる、下位42%＝堅め）を決め、以降は変更しない。レポートは「式づくり期間」「検証期間（9/28以降）」「公開後（11/6より後）」を分けて出す。
- 作成時点の検証期間（1,742R）：荒れると見た536本の41.2%が荒れた（全体30.3%）。堅めと見た750本の78.8%が堅く決着（全体69.7%）。チャッピー的中率は荒れる16.6%／混戦23.2%／堅め30.7%。回収率はどれも約64〜67%で差がない。

## 2. チルト

- 実際の進入コース×チルト（-0.5／0／+0.5／+1〜1.5／+2以上）ごとの1着率・3着内率を、そのコース平均と比べる。Wilson 95%区間で平均の外にあるものだけ「上／下」、25艇未満は判断保留。3.5超は入力誤りとして除外。
- 作成時点：4コース+2以上は1着34.5%（29艇、平均11.6%）で「上」。5コース+1〜1.5は「下」、1コースは跳ねるほど1着率が下がる傾向。特定選手への偏りは見られない。

## 3. モーター

- 2026/10/27（#1385）までに保存された予想は、`motor2Rate`/`motor3Rate` が公式値ではなく内部点数の再エンコード値（motor3 = motor2 + 15）だった。`motorSource()` で判定し、公式値と分けて集計する。
- 作成時点（公式値690R）：1コースのモーターが6艇中1〜3番目ならイン1着約56〜62%、6番目は42.7%。

## 4. 場

- 場ごとのチャッピー的中率・回収率を前半／後半（9/28で分割）で出す。的中率は前後半で相関0.45と傾向が続くが、回収率は相関-0.16で偶然の大当たりに左右されるため、場の選別に回収率を使わない。
