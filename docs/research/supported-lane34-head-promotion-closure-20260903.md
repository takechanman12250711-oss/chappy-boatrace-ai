# 3・4号艇「下位支持からの頭昇格」研究 終了記録

更新日: 2026-09-03 JST  
基準main: `6e14f47aa2a1cf2ce851948de688581091981e8a`  
対象PR: #798〜#805

## 結論

この研究枝から、3・4号艇を本番の1着候補へ追加・昇格する変更は採用しない。

保存済み上位24候補で1着欄には存在しないが、2・3着欄には高得点で現れている3・4号艇には、実際の勝ち艇を含む信号がある。ただし、事前条件で誤昇格を十分に抑えながら、最大払戻への依存を除いて舟券回収率を安定して100%以上にする条件は確認できなかった。

`passingConfigIds` は空で、研究ゲートを通過した条件は0件だった。

## 過去研究との重複確認

この枝を本番変更へ進めない理由には、既存の棄却結果も含む。

- PR #317: 3号艇の候補限定昇格は期間間で安定せず棄却。
- PR #318: 4カド理論が成立していても、単純な4頭昇格は正しい1逃げ・2差しを多く壊すため棄却。
- PR #331〜#334: 1逃げから3攻めへ切り替える物理条件を段階検証したが、最終的に直近期間を悪化させ、安定条件なしで終了。

#798〜#805は、これらを単純に再実施したものではなく、「真の勝ち艇が上位24候補の頭から消えていても、下位位置には残っている」という別の欠落経路を診断した。しかし、最終的な本番採用判定は既存の棄却結論と同じになった。

## 今回確認したデータ

### 1. 候補機会の全体像

研究対象は、次の事前条件を満たす3・4号艇。

- 保存済み上位24候補に1着候補として存在しない
- 同じ上位24候補の2着または3着には存在する
- 保存時の支持スコアが85点以上

該当は1,089レース・1,402候補機会。

- 実際にその艇が1着: 110件
- 誤昇格となる候補: 1,292件
- 無条件の頭化率: 7.8%

したがって、「下位に高得点でいる」という理由だけで頭へ上げることはできない。

### 2. 的中候補と誤昇格候補を分けた主な信号

PR #804の事前特徴比較で、分離に比較的使えたのは次の順だった。

1. 展示タイムの全艇最速との差・順位
2. 下位24候補内での反復出現回数
3. 内側艇に対する平均ST差
4. 内側艇に対する展示タイム差

一方、モーター2連率順位は頭的中候補を正方向に分離せず、展示STも有効な昇格条件として採用しなかった。

主な単独集計:

- 平均STが内艇より0.03以上速い: 頭化率13.7%
- 今節STが内艇より0.03以上速い: 頭化率12.3%
- 展示タイムが内艇より0.03秒以上速い: 頭化率12.9%
- 展示タイム1〜2位: 頭化率11.5%
- 展示タイム5〜6位: 頭化率4.5%
- 風速5m以上: 頭化率5.3%
- 3着位置だけで支持された候補: 0/75件

## 舟券化で分かったこと

今回の重要な発見は、「頭艇を見抜く問題」と「2・3着を組む問題」を同一処理にしてはいけないこと。

ST・展示の二重確認で3・4号艇の1着率は上がったが、保存候補の2着得点1位＋3着得点1〜2位という単純な相手生成では、評価期間の正解舟券を拾えなかった。

ただし、この結果を理由に相手点数を広げる研究を続けると、既に棄却した広い買い目追加・置換を別名で再試験することになる。よって、この枝では相手拡張へ進まない。
