# チャッピーボートレースAI ACTIVE WORK PLAN

更新日: 2026-10-15（JST）

## 今進める作業は1件

**1号艇が逃げたレースの2着相手選定を、現行と同一レース・同一点数で比較する。**

最新の引き継ぎは [Issue #1214の10月15日報告](https://github.com/takechanman12250711-oss/chappy-boatrace-ai/issues/1214#issuecomment-6181265639)。同報告の現行近況99Rでは1号艇勝ち58Rのうち1・2着組不足が25R。25Rは原因を追う対象であり、それだけで改善の優劣を決めない。現行の的中を失う件数も含め、同一対象・同一点数の比較と期間別の的中率・回収率を確認する。

保存時点の展開・進入・ST・展示・残し/拾いの根拠を使う。結果やオッズで候補を選び直さず、過去予想を上書きしない。候補の本番採用と安定した精度向上は未完了。
