# 200円の試行（2026-10-04ユーザー承認）

- 対象: 今後新規公開するnormal・escape・manshuの各記事。1記事200円。既存公開記事の価格と購入済み履歴は変更しない。
- 正本: `scripts/note-pricing.js`。新規handoff、投稿前検査、価格入力、匿名公開検証は200円で統一する。300円の古いhandoffはそのまま投稿せず、保存原本から現行価格の公開用コピーを作る。
- 過去のreceiptは公開時の300円を保持し、現行200円とともに読み取る。種類別予約・元原稿・買い目・締切・有料境界・公開照合は維持する。
- 試行開始: main反映日ではなく、200円の最初の公開成功receiptと公開ページ確認を開始証拠にする。本ドキュメントは設定の承認記録であり、200円での公開・販売・購入の証拠ではない。

## 継続購入の確認

- noteの販売履歴を一次資料として、200円記事の販売数・購入者数・売上・手数料控除後売上を確認する。公開receiptは掲載証拠であり、購入データではない。
- 継続購入は「200円記事の初回購入後、別の日本時間の日に再購入した人」を主に見る。同日や同一レースの複数種類購入は別に数え、継続購入に含めない。
- 7日間の再購入を見る場合は、初回購入から7日経過した購入者だけを分母にし、その後7日以内かつ別日に再購入した人数を分子にする。観測期間未了は待機、照合できない購入者は不明として人数も示す。未購入・不明・欠測を再購入0件と扱わない。
- 300円期との比較では、価格だけでなく本文構成、公開数、対象レース、閲覧数の違いも記録する。比較前に分母を揃え、少数や同時変更で価格の効果を断定しない。
- 購入者の識別情報や販売CSVを公開リポジトリへ保存しない。集計する際も元データは非公開で扱う。
- noteには販売履歴CSVの書き出し機能があるが、現在のアカウントで取得可能な列・購入者照合・自動取得経路は未確認。自動集計や常時監視は稼働済みとしない。本文・表紙の承認済み編集案の実装状況は価格変更と分けて管理する。
