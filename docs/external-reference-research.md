## 大村比較の実装契約

- 既存 `live-note.yml` の公開handoff後に独立jobを実行する。予想・記事生成の中で外部取得を待たない。5分間隔の既存scheduleを使用し、新しい常駐タスクや有料サービスを追加しない。
- 入力は `data/note-drafts` の通常 `all-races-v1` 原本だけ。SHA、独立した実戦券との一致、公式展示、締切前・結果未使用の記録を検証する。監視イン逃げ・万舟原稿を通常予想へ混合しない。
- 当日大村、保存から15分以内、公式締切まで120秒超だけ取得する。取得完了後にも時計を再検査する。過去レースの後付け収集は禁止。
- 公開モバイル直前ページを最大12R、各7秒、全体90秒まで取得する。ログイン・課金・アクセス制限回避は行わない。失敗はartifactに理由を記録し、note公開の成否と分ける。
- HTML metaのShift_JISを尊重する。展示後見出し、本文の日付・R、更新時刻、締切、本命、狙い目、6艇の展示タイム・展示ST・実進入を検証する。前日予想へ代替しない。未対応の買い目表記は全体を拒否し、読めた部分だけ採用しない。
- 外部と保存原本の6艇の展示が一致したものだけ `captured`。取得時差、双方の点数、各着の艇集合、共通券を残す。同時刻と断定しない。
- `data/omura-reference/YYYYMMDD/<raceKey>-<SHA256>.json` に不変保存。本命と狙い目は別配列。記事全文・短評は複製せず、数値・買い目・出典URL・レスポンスSHA・取得時刻を保存する。
- 成績に使うのは各Rの最初の有効保存のみ。後の版から当たりを選ばない。締切後の既存 `data/results` と共通の公式結果契約で照合し、不成立・返還は別扱い、結果待ちは未確定とする。
- `omura-reporter-reference` artifact の `report.json` に全対象の記述集計と「同点数かつ取得差5分以内」の別集計を出す。対象0件の的中率はnull。1着不足・1/2着の組不足・3着不足を分ける。狙い目を本命の的中率へ足さない。
- これは大村・保存済み通常予想という限定母集団の比較用。投資成績・売上効果・改善実証とは区別する。採用gate未登録。`productionChanged=false`、`automaticProductionChange=false`、`usableForPrediction=false` を維持する。

## note販売への反映方針

既存の固定案内・日次一覧・レース別記事を使い、通常／イン逃げ／万舟の区分を維持する。購入前の説明は「誰向けか、何Rか、締切、点数、展開の焦点、取得できた情報」を明確にする。外部の買い目や文章の転載で商品を作らない。

効果判定は取得可能なnoteの閲覧数・購入数・売上を同じ期間で記録してから行う。現時点で競合の売上・購入率は取得していない。価格300円を競合価格だけで変更しない。表紙や無料部分を変える際も一度に変更項目を絞り、通常／イン逃げ／万舟別に確認する。
