# データ攻め由来の3ルールの比較テスト（datazeme-shadow-ab-v1）

2026-11-07 ユーザー依頼「skillをうまく活用してから改善、検証に役立てて」。`chappy-source-research`（外部理論をshadowで検証する手順）と `chappy-result-learning`（良化した要素だけ抽出、回収率を無視しない）に沿って作成。**研究用。本番の予想・買い目・note は変えない**（`productionChanged/usableForPrediction/automaticApplication = false`）。

## ルール（結果を見る前に固定：`config/datazeme-shadow-ab-v1.json`）
- A：現行（保存した実戦厳選をそのまま買う）
- B1：race-roughness-v1 が rough のレースを見送る（締切前保存の進入・風・波で判定）
- B2：展示の進入で4コースの艇がチルト+2.0以上、かつチャッピーの1着軸がその艇でなければ見送る
- B3：チャッピーの1着軸が1コースの艇で、その公式モーター2連率が6艇中単独最下位なら見送る（公式値が保存された期間だけ判定）
- 1着軸＝保存した実戦厳選で1着に置かれた回数が最多の艇

すべて「買わない」ルールで、数字だけで新しい券を足す案は入れていない（憲章どおり）。

## 期間
- explored：〜2026-11-06（傾向を見つけた期間。良く見えやすい参考値）
- holdout：2026-11-07〜（初めて見る期間）。300R程度たまってから判断する。

## 作成時点の結果（explored・参考）
| | 買うR | 的中率 | 回収率 | 見送った分の回収率 |
|---|---|---|---|---|
| A 現行 | 4,470 | 24.3% | 75.2% | - |
| B1 荒れそう見送り | 3,112 | 27.2% | 77.2% | 71.0%（1,358R） |
| B2 4コース跳ね見送り | 4,453 | 24.3% | 75.3% | 44.5%（17R） |
| B3 インのモーター最下位見送り | 4,443 | 24.2% | 75.2% | 86.4%（27R） |

- B1 は的中率+2.9pt、回収率+2.0pt。ただし式を作った後の期間（9/28〜11/6）だけで見ると、荒れ見立て別の回収率はほぼ同じ（65.5% / 67.0% / 63.9%）で、回収率の改善はまだ確かではない。
- B2・B3 は件数が少なすぎて判断できない。B3 は見送った27Rの方が成績が良く、今の形では逆効果の可能性がある。
- 主要な数値（A と B1）は Python で別に再計算して一致を確認（4,424R：A 24.2%/75.2%、B1 残り 27.1%/77.4%、見送り 17.5%/70.6%）。

## 採用
holdout で回収率の改善が確認できた要素だけを、予想ロジック変更として本人の別承認を得て採用する。このテスト自体は何も採用しない。
