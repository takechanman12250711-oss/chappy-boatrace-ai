# 当地・水面 5・6号艇頭・最終選択監査 v1

## 目的

締切前に当地・水面の正式証拠が保存され、公式結果まで確定した同一コホートだけを対象に、実際の5・6号艇頭がどの役割で保存され、最終主シナリオへ到達しなかったかを監査する。

## 役割の厳密な区別

- 頭候補: `headBoatNo` 等の明示フィールド、舟券の1着位置、`head` / `alternate-head` 役割、または1着適格位置
- 相手・拾い: 2着候補、3着候補、hold、pickup、support
- 相手・拾いとして登場しただけの艇を頭候補へ数えない

## 事前固定した次工程

1. 実5・6号艇頭が20R未満: 収集継続
2. 実際の勝ち艇の頭候補被覆が50%未満: 頭役割の候補生成を監査
3. 候補からシナリオへの被覆低下が10pt以上: シナリオ昇格を監査
4. シナリオから選択済み候補への被覆低下が10pt以上: 候補順位付けを監査
5. シナリオ被覆と最終正解率の差が10pt以上: 主シナリオ順位付け・引き渡しを監査
6. 上記以外で最終正解率20%未満: 外枠頭の順位順を監査

## 安全性

診断専用。予想ロジック、買い目、点数、UIへ自動適用しない。
