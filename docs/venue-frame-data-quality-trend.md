# 場別枠データ品質トレンド

場別枠検証データの品質指標を日次保存し、短期的な悪化傾向を監査表示する機能です。

## 記録対象

- 全検証件数
- 隔離件数
- 隔離率
- 再隔離率
- 未処理の復旧候補数
- 集計対象外件数

## 保存仕様

- 同じ日は最新値で上書き
- 最大90日分を端末内の `chappy_venue_frame_data_quality_trend_v1` に保存
- 元データは変更しない

## 傾向判定

直近3日平均と、その前3日平均を比較します。

- 隔離率が5ポイント以上悪化: 注意要因
- 再隔離率が10ポイント以上悪化: 注意要因
- 未処理件数が平均3件以上増加: 注意要因
- 注意要因が1つ: 注意
- 注意要因が2つ以上: 悪化
- 履歴が2日未満: 蓄積中

## 安全条件

- 監査表示と履歴保存のみ
- 予想処理を停止しない
- 予想ロジック、印、配点、買い目を変更しない

## 読み込み

`js/venue-frame-data-quality-trend-loader.js` をページから読み込むと、本体の `js/venue-frame-data-quality-trend.js` が自動接続されます。
