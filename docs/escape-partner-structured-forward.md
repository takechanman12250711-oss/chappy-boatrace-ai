# 逃げ相手候補の構造化根拠・前向き比較

`candidateValidationEvidence` が締切前に保存した根拠だけを使い、既存買い目と同数で相手候補を比較する研究レポートです。本番予想は変更しません。

- 発見期間は `20261017` に固定する。
- 前向き期間は設定の `registeredAt` 以降に保存され、締切前であるレースだけを集計する。
- 1頭候補は、同じ `scenarioId` の `validPurchaseBranchIds` で1・2・3着の全位置が成立する場合だけ使う。
- `physicalCoverage` は代用しない。
- 1頭買い目で重複する2着艇のうち、本線・流し以外の低い優先度1点とだけ交換する。候補優先度が厳密に高くない場合は変更しない。
- オッズと結果は候補選択に使わない。公式結果は選択後の同一レース・同一点数評価だけに使う。

既存の `escape-main-audit.yml` が日次でレポートを再生成・保存します。前向き母数が不足している間の結論は `INSUFFICIENT_EVIDENCE` で、採用判定や自動適用には使いません。
