# 場別枠データ品質週次サマリー

日次のデータ品質トレンドを週単位で集計し、前週との変化を確認する監査専用機能です。

## 集計対象

- 隔離率
- 再隔離率
- 未処理件数
- 集計対象外件数

## 週の区切り

月曜日を週の開始日として集計します。

## 判定

### 悪化

次のうち2項目以上に該当した場合です。

- 隔離率が前週より5ポイント以上上昇
- 再隔離率が前週より10ポイント以上上昇
- 未処理件数が前週より3件以上増加
- 集計対象外件数が前週より3件以上増加

### 改善

次のうち2項目以上に該当した場合です。

- 隔離率が前週より5ポイント以上低下
- 再隔離率が前週より10ポイント以上低下
- 未処理件数が前週より3件以上減少
- 集計対象外件数が前週より3件以上減少

上記以外は横ばい、比較対象がない場合は蓄積中です。

## 保存

週次集計は `chappy_venue_frame_data_quality_weekly_v1` に最大26週分保存します。

## 安全条件

- 元データを変更しない
- 予想処理を停止しない
- 予想ロジック、印、配点、買い目を変更しない
- 監査表示と履歴保存に限定する

## 読み込み

`js/venue-frame-data-quality-weekly-summary-loader.js` をページから読み込むと、本体が自動接続されます。
