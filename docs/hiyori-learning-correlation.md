# 日和互換データ 結果相関分析

保存済みの学習スナップショットとレース結果を照合し、各情報が着順へどの程度結び付いたかを監査・観察する機能です。

## 集計対象

- 展示タイム順位
- 一周タイム順位
- 合成オッズ順位
- ST展示順位
- 気象・水面区分
- 新エンジン／通常エンジン
- 新燃料／通常燃料

## 表示指標

各区分について以下を表示します。

- サンプル艇数
- 1着率
- 2連対率
- 3連対率

## 気象・水面区分

- 穏やか
- 中程度
- 強風・高波

初期区分は風速・波高を使った観察用分類です。

## 保存

分析結果は `chappy_hiyori_learning_correlation_v1` に保存します。

## 更新

- 学習スナップショット保存時
- 結果照合時
- localStorage更新時
- 1分ごと

## 安全条件

- 予想ロジックへ自動反映しない
- 印を変更しない
- 配点を変更しない
- 買い目を変更しない
- 相関結果は観察・検証専用とする

十分なサンプルが集まった後、予想へ反映する場合は別途変更案を提示し、承認後に実装します。
