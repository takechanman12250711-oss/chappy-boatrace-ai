# 日和データ 最終承認パッケージ

## 目的

本番反映前の最終判定ゲートで「最終承認待ち」になった提案だけを、署名付きの固定パッケージとして保存する。

## 保存内容

- 提案ID
- 分析グループ・条件
- 反映対象
- 補正上限
- 相関信頼度
- 相関サンプル数
- シャドー検証件数
- シャドー成績
- 改善率・悪化率・差引
- 平均順位上昇幅
- 総合準備度
- 中止条件
- 安全ロック状態

## 改ざん・変更検知

パッケージ内容を安定化した文字列から署名を作成する。保存後に内容が変更された場合は署名不一致として表示し、承認対象外とする。

## 安全仕様

- `finalApproved: false`
- `productionApplied: false`
- `appliedToPrediction: false`
- `applicationLock: true`
- `globalProductionLock: true`
- 予想優先順位は変更しない
- 合成オッズで買い目を作成・削除しない
- パッケージ生成だけでは本番反映しない

## 中止条件

- 相関信頼度72点未満
- 相関サンプル120艇未満
- シャドー検証120件未満
- 悪化率18%以上
- シャドー判定が採用検討未満
- 提案内容または補正上限の変更
- 最終承認から30日経過

この機能は監査・承認準備専用であり、予想ロジック、印、配点、買い目、資金配分には影響しない。
