# 自信度と回収率（勝負所の検証）v1

更新日: 2026-10-22

## 位置づけ

YouTube「【今日から真似できる】ボートレースで月100万円以上稼ぐ舟券プロ達の7つの共通点！」（フナフェッショナル／あべけん、https://www.youtube.com/watch?v=7kS9-_UTS9I ）の7番目「自信のある勝負レースにだけ資金を集中する」を、締切前保存予想と公式結果で確かめた**研究集計**。同じ動画の3番目（大穴1発狙いはやらない）は `docs/trifecta-popularity-roi-v1.md` で検証済み。

- `productionChanged=false` / `automaticApplication=false` / `usableForPrediction=false`。本番予想・買い目・購入金額は変えない
- 主張の出典はユーザーが作成した動画要約（動画本体は未視聴）
- 入力は `data/predictions`（`analysis-input-contract` の締切前判定を通したもの）の `prediction.confidence.score`・`selection.score`・`prediction.practicalTickets` と、`data/results` の公式結果

再生成: `node scripts/build-confidence-stake-roi.cjs` → `data/stats/confidence-stake-roi-v1.json`

## 結果を見る前に固定した条件

| 項目 | 値 |
| --- | --- |
| 買い方 | 保存済みの実戦厳選（`practicalTickets`）を各100円。券がないレースは見送り |
| 期間 | explored 2026-07-22〜09-15 / holdout 2026-09-16〜 |
| 帯 | スコアをexploredの三分位で低・中・高に分け、同じ境界をholdoutに当てはめる |
| 対象スコア | 自信度（`confidence.score`）と選定スコア（`selection.score`） |
| 除外 | 欠場・F・出遅れのあるレース、3着以内の同着、収集途中（`complete: false`）の結果日 |
| 「勝負所の根拠あり」 | 両期間とも、高帯の回収率が100%以上かつ低帯を上回り、どちらの帯も100R以上 |

## 結果（2026-07-23〜10-21、3,229R）

除外: 締切前判定で16件（締切後保存6・締切後取得3・時刻欠落7）、レース単位で549件（収集途中の結果日11日分457、欠場・F・出遅れ91、同着1）。

全体: explored 1,754R 的中24.6%・回収73.9%、holdout 1,475R 的中25.2%・回収82.6%（平均8.5〜8.8点）。

## 読み取り

1. **自信度が高いレースは、少し当たりやすいが、回収率は上がらない。** 高帯の的中率は両期間とも低帯より3〜4ポイント高い。しかし回収率は高帯で77.7%・74.7%と100%に届かず、exploredでは低帯（79.0%）を下回る。holdoutの中帯118.5%は、帯の順に並ばず、少数の高配当に引っ張られたばらつきと見られる。
2. **選定スコアは結論を出せない。** 欠測が多く、holdoutの分布がexploredと違うため、帯の比較が成り立たない。
3. **今のスコアには「ここで大きく張る」根拠がない。** 動画の7番目は、自信の高いレースが実際に儲かることが前提になる。保存済みの自信度では、その前提を確かめられなかった。賭け金を自信度で増やすと、外れたときの損が大きくなるだけになる可能性がある。

## 未検証・既知の限界

- 期間は約3か月。回収率は少数の高配当で大きく動くため、帯ごとの値はぶれやすい。
- 保存された実戦厳選券を100円ずつ買った場合で、実購入の金額・券とは違う。
- 自信度・選定スコアの算出方法は期間中に変わっている可能性がある。

## 次に検証できること

- 回収率は高配当1件で大きく動くので、件数が増えた時点で同じ固定条件のまま再集計する。
- 賭け金の増減や購入の歯止め（chappy-boatrace-api の購入の歯止め）に自信度を使うかどうかは、この結果を踏まえて本人が判断する。採用には別の承認が必要。
