# 場別枠データ品質アラート

場別枠検証データの隔離・復旧状況を監視する監査専用機能です。

## 判定対象

- 隔離率
- 再隔離率
- 未処理の復旧候補数
- 集計対象外データ数

## 初期しきい値

### 隔離率

- 10%以上: 注意
- 20%以上: 要対応
- 母数20件未満では率による警告を出さない

### 再隔離率

- 15%以上: 注意
- 30%以上: 要対応
- 復旧判定が3件未満では率による警告を出さない

### 未処理件数

- 5件以上: 確認
- 10件以上: 注意

### 集計対象外

- 10件以上: 注意

## 保存

アラート状態が変化した時だけ、`chappy_venue_frame_data_quality_alerts_v1` に最大300件保存します。

## 安全条件

- 元データを変更しない
- 予想処理を停止しない
- 予想ロジック、印、配点、買い目を変更しない
- 監査表示と履歴保存に限定する

## 読み込み

`js/venue-frame-data-quality-alerts-loader.js` をページから読み込むと、本体の `js/venue-frame-data-quality-alerts.js` が自動接続されます。
