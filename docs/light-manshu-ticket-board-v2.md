# 「取れたらいいな舟券」別枠ボード v2

更新日: 2026-09-03 JST

## 目的

通常予想とは別に、スタート波乱、外の攻め連動、内残し、展開拾い、道中の入れ替わりから成立する「取れたらいいな」の参考舟券を複数提示する。

これは本線の的中率を上げるための追加買い目ではない。予想屋が「本命は別だが、この展開まで少額で持つなら」と示す任意の参考プランである。

## 画像例から縮小した配分

参考画像の `10枚 / 6枚 / 3枚` をそのまま使うと、展開後33点、合計25,200円になる。今回の別枠は少額参考に限定し、次の上限へ縮小する。

| 項目 | v2の上限 |
|---|---:|
| 筋数 | 3筋 |
| 1筋の展開後点数 | 2〜4点 |
| 全体点数 | 12点 |
| 1枚 | 100円 |
| 筋ごとの配分 | 順位順に各3枚・2枚・1枚 |
| 最大参考額 | 2,400円 |

弱い筋で上限まで埋めない。成立筋が2つ未満なら新しい別枠ボードを表示せず、v1の既存穴候補説明だけを残す。

## 生成順序

1. 正式な事前展開のうち、2コース差し、3コース攻め、4カド攻めを読む。
2. 4〜6号艇について、攻め艇、直外の追走艇、または道中力を伴う展開拾い艇かを確認する。
3. 2・3着は同じ展開が正式に保持する着順候補だけを使う。
4. 頭と展開を1筋ごとに固定し、裏付け済みのexact 3連単だけを2〜4点のフォーメーションへ圧縮する。
5. 筋の成立度順に各3枚・2枚・1枚の参考配分を付ける。

頭候補は攻め艇を含め、事前の1着評価が60点以上であることを必須とする。非攻め艇を頭にする場合は、さらに次のどちらかを満たす必要がある。

- 攻め艇の1〜2コース外から追走・連動・まくり差しできる根拠がある。
- 展開拾い・最内・道中の根拠があり、既存の道中候補かつ道中役割点65点以上である。

blocked艇、「攻め場減少」、展開不利などの否定根拠がある艇は、新規参考舟券の1〜3着へ使わない。実進入が変わった場合は、枠番ではなく公式展示進入の物理艇とコースを使う。

## 表示契約

表示名は `取れたらいいな舟券` とする。

- 通常予想とは別枠の任意参考プランであることを常時表示する。
- `1点あたり3枚（300円）` のように、枚数が各exact券に掛かることを明示する。
- 展開後点数、組ごとの参考額、全体参考額を表示する。
- フォーメーションを開くと、全exact券と個別の展開説明を確認できる。
- 的中確率、購入推奨、鉄板、期待値があるとは表現しない。
- オッズ未取得でも生成できるが、実オッズ100倍以上を保証する名称にはしない。
- 実戦厳選が明示的に `selected` の場合だけ表示し、未生成・取得不能・エラー・見送りでは表示しない。
- 実戦厳選はボード生成後に確定するため、選ばれた実戦券と1点でも重複した場合は、別枠ボード全体を表示しない。

## 分離境界

正本はトップレベルの `prediction.lightManshuTicketBoard` とし、`prediction.aiCore.lightManshuTicketBoard` は同値の互換ミラーだけを保持する。

次の購入候補配列へ追加しない。

- `formations`
- `ticketSheets`
- `manshuSheet.tickets`
- `aiTicketList`
- `practicalSelection.tickets`
- `practicalTickets`

また、note、自動購入、購入保存、実戦成績、A/B候補、通常予想の最大7点へ接続しない。

出力には次を記録する。

```text
displayOnly: true
advisoryOnly: true
purchaseEligible: false
saveEligible: false
noteEligible: false
usesOdds: false
usesOfficialResult: false
changesNormalTickets: false
changesPracticalSelection: false
```

## v1・棄却済み研究との区別

既存の `lightManshuScenario` は、通常穴候補1点の説明としてそのまま維持する。

3・4号艇頭昇格研究の `REJECT_AND_CLOSE` も維持する。v2は通常予想の1着候補や印を昇格せず、通常舟券へ追加しない。外艇頭は、明示された軽い波乱シナリオの表示専用参考枝としてだけ扱う。

## 機械検証

- 最大3筋、各2〜4点、全体最大12点、最大2,400円
- フォーメーション再展開と全exact券の完全一致
- 同一艇重複券、筋間重複券、既存通常券の排除
- 同じ展開内の2・3着候補だけを使用
- 起点展開の固定と、公式進入の物理艇対応
- blocked・攻め場減少の排除
- 道中役割点64では不採用、65以上だけ道中浮上を許可
- オッズ・公式結果を加えても候補、順位、枚数が不変
- v1の既存穴説明が不変
- 新フィールドを除いた通常予想、実戦厳選、note入力、購入候補、A/B指紋が不変
- 通常経路とiPhone復旧経路が、更新済みAIコアと描画を同じキャッシュ世代で読む
