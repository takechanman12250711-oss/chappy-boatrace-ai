      同期用の合言葉（トークン）

      ふだんは作らず、すでにある合言葉を使ってください。Vercel の chappy-boatrace-api →「Settings」→「Environment Variables」の CHAPPY_PURCHASE_SYNC_TOKEN の値をコピーして、上の欄に貼り付けます。この合言葉は5分ごとの自動精算や最終オッズの収集（GitHub Actions）でも使っています。

      「合言葉を作る」は、値を表示できないなどで新しくするときだけ使います。この端末の中だけで作り、どこにも送りません。作ったら、Vercel の環境変数と GitHub の Secret（chappy-boatrace-ai →「Settings」→「Secrets and variables」→「Actions」の CHAPPY_PURCHASE_SYNC_TOKEN）の両方を同じ値に置き換え、Vercel をデプロイし直してください。片方だけだと自動精算が止まります。

      作った合言葉は、iPhoneの「パスワード」アプリにも保存してください（タイトル「チャッピー購入同期の合言葉」）。合言葉は開いたブラウザごとに別々に保存され、Vercel と GitHub では後から見られません。消えたときはパスワードアプリからコピーして上の欄に貼れば、作り直さずに済みます。

      チャッピーの購入同期APIにだけ送ります。チャットやSNSには貼らないでください。

      ブックマークの登録（最初の1回だけ）

      1. 下の「コピー」を押します。
      2. このページをブックマークに追加し、名前を「チャッピー取り込み」にします（Chromeは右下の「…」→「ブックマークに追加」）。
      3. ブックマークを編集し、URL（アドレス）をコピーした文字に置き換えて保存します（Chromeは「…」→「ブックマーク」→ 長押し →「ブックマークを編集」）。
      4. BOAT RACE公式サイトの投票照会（またはテレボートの投票履歴）を開き、そのブックマークを押すと、このページが開きます。スマホのChromeでは、アドレス欄に「チャッピー取り込み」と入力し、☆の付いた候補を押します。
      5. 照会の「合計」のタブで押すと、その日の購入金額・払戻を送れます（1日の負けと月の予算はこの合計で判定）。一覧で入れた金額との照合にも使います。

      ブックマークは画面の表の文字を読み、各明細の No を順に開いて金額を読んでから閉じます（24件で数秒）。どこにも送信しません。送信はこのページで確認してから行います。
